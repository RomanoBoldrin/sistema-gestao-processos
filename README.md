# ESTRADA — Sistema de Gestão de Processos

Sistema web desenvolvido para apoiar a gestão de processos administrativos no escritório **Estrada Sociedade Individual de Advocacia Ltda.**, com foco em licitações, contratos públicos e processos disciplinares.

O objetivo do projeto é **centralizar o cadastro de processos**, organizar documentos jurídicos e **controlar prazos com alertas visuais**, reduzindo riscos operacionais e melhorando a eficiência da equipe.

Este projeto faz parte do **Projeto Integrador (UNIVESP)** e está sendo desenvolvido de forma incremental, com validação contínua junto à comunidade externa.

## Funcionalidades (em desenvolvimento)

- Cadastro e listagem de processos administrativos
- Registro e acompanhamento de prazos
- Destaques visuais para prazos críticos (próximos do vencimento ou vencidos)
- Estrutura preparada para upload e associação de documentos
- Base para dashboards e indicadores gerenciais

## Tecnologias utilizadas

- Next.js (Pages Router)
- PostgreSQL
- Prisma ORM
- Jest (testes automatizados)
- Git/GitHub (controle de versão)
